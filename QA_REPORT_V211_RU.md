# Voyah Manager 2.1.1 — исправления интерфейса

Дата: 15 октября 2026 года. Выпуск исправляет замечания по снимкам пользователя.

## Изменения

- «APK с ПК» — единая компактная рабочая область. Список непосредственно под зоной
  перетаскивания, параметры и установка остаются на экране; длинная очередь
  прокручивается внутри таблицы. Блок «Технические подробности» удалён.
- Файл можно убрать собственной кнопкой корзины. Delete убирает выбранные строки;
  отдельная корзина рядом с выбором режима очищает очередь. Файлы ПК не удаляются.
- Перетаскивание сразу показывает результат добавления. Повторный путь не создаёт
  дубликат, включая различия регистра и относительную запись пути в Windows.
  Файлы с одинаковым именем из разных папок остаются отдельными записями.
- Изменение очереди блокируется на время операции и административным профилем.
  Отложенное чтение папки после очистки/удаления/начала установки игнорируется.
- Пояснение клавиатур занимает ширину карточки. У вкладок инспектора отключена
  стандартная линия подложки. Значки пустых состояний не сжимаются по высоте;
  фон под закладками файлового менеджера прозрачен.
- Кнопки мини-пульта убраны из верхней панели. Выбор внешнего ADB убран:
  приложение использует только проверенную встроенную копию, старые настройки
  пути к внешнему ADB не влияют на запуск.
- Масштаб: 80–260, шаг 20 плюс ранее доступное 150, с понятными подписями RU/EN.
  Ручной ввод ограничен тем же диапазоном. «160 — стандарт» — опорный пресет,
  заводское значение конкретной прошивки может отличаться; сброс возвращает
  значение прошивки, а не принудительно 160.

## Проверки

Результаты полного набора, автономного EXE и контрольные суммы фиксируются после
сборки в приложенном манифесте и ниже в автоматическом отчёте CI.

Проверки не подключают реальное головное устройство. Установочные команды,
системные сценарии и ограничения прошивок сохраняются из 2.1.0. Аппаратный
чек-лист и подробный предыдущий отчёт приложены отдельно.
