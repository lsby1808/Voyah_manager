# Voyah Manager 2.1.2 — пароль меню, демо и автоматическая установка

Дата: 15 октября 2026 года.

## Реализовано

- Текущий пароль инженерного меню в верхней панели. Алгоритм проверен по
  предоставленному EXE: Пекин UTC+8, суммы десятичных цифр без сокращения
  двузначной суммы. По нажатию — сегодня/вчера/завтра с датами и копированием,
  отдельный блок постоянных вариантов ранних прошивок. Детали: `REVERSE_PASSWORD_RU.md`.
- Админ-меню → «Функции» → «На этом компьютере»: демонстрационный режим
  с применением через перезапуск. Выбор хранится локально и не публикуется в
  каталоге. Перезапуск блокируется при задании или наблюдении; ошибка запуска
  возвращает прежнюю настройку. В демо команды автомобиля идут в имитатор.
- Ручной список способов установки убран. Один APK устанавливается отдельно,
  независимые APK — по очереди, части одного пакета и версии — одной транзакцией.
  Разбор выполняется по манифесту через AAPT2, а не только по количеству/именам.
  APKS/XAPK/APKM остаются отдельными комплектами с прежней обработкой OBB.
  Неоднозначные комплекты без единственного base отклоняются до установки.
- «Кнопки руля»: отдельные компактные карточки управления и результата;
  таймер и состояние в одной строке, экспорт компактными кнопками с подсказками.
  В ожидании показана короткая строка; категории и ограниченная по высоте запись
  появляются после завершения. У результатов явные границы и прозрачная подложка.

## Проверки

Проверяются границы суток/года по Пекину, двузначные суммы, RU/EN, копирование,
геометрия заголовка; локальная настройка демо, отсутствие реальных команд в демо,
отказ перезапуска при занятой программе и возврат настройки при ошибке; группировка
APK по пакету/версии и реальная проверка извлечённых APK через AAPT2; шесть секунд
захвата, компактное ожидание и раскрытие результатов, прежняя функциональность.

Итоговые результаты CI, SHA-256 и проверка EXE фиксируются после сборки.
Реальное ГУ не подключалось; пароль и системные изменения на автомобиле не проверены.
