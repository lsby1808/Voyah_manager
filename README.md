# Voyah Manager 2.0

Автономный Windows GUI для Android-ГУ Voyah: приложения, две клавиатуры, диагностика,
файлы, твики, восстановление и ADB. Исходник приложения — один `voyah_manager.py`.

- [Скачать Windows EXE](https://github.com/lsby1808/Voyah_manager/releases/latest)
- [Инструкция](README_RU.md)
- [Отчёт локальных проверок](QA_REPORT_RU.md)
- [Проверки автомобиля](HARDWARE_CHECKLIST_RU.md)
- [Общий каталог](catalog.json)
- [Сборки GitHub Actions](https://github.com/lsby1808/Voyah_manager/actions)

Адрес этого репозитория встроен в клиент. `catalog.json` редактируется и публикуется
в админ-меню; обновление каталога не требует пересборки EXE. Первоначально список APK
и клавиатур пуст: владелец добавляет ссылки на разрешённые к распространению файлы.
Код входа хранится только в виде проверочного хеша. Токены и локальные резервные копии
не входят в репозиторий и EXE.

Изменение исходника запускает проверку и сборку Windows EXE. Изменение только
`catalog.json` не запускает пересборку. После успешной проверки EXE публикуется в Releases
вместе с SHA-256. Для повторной сборки можно запустить workflow вручную.

Сборка не подписана. Root/remount, клавиатуры, Qinggan Settings и dm-verity проверены
на имитаторе; совместимость с реальным ГУ не подтверждена. «Починить verity» отключает
dm-verity по процедуре отчёта и не включает проверку разделов.

Python/Qt зависимости и GitHub Actions зафиксированы; `tools.lock.json` проверяет
SHA-256 архивов ADB, Java и bundletool. При изменении архива upstream сборка останавливается
до осознанного обновления lock-файла. Сам EXE содержит необходимые инструменты.
